# 區塊紀錄：兩張舊頁面的每一塊現在在哪裡

這份紀錄對照基準版的兩張頁面與現在的單一頁面。基準版是 git 標籤 `baseline` 的 `soxl_analysis_report.html`（完整報告，52 塊）與 `soxl_simple.html`（新手版，30 塊）。每一塊一列。每一列寫明結果、現在的位置、理由。刪除的檔案另有一張表，每個檔案一列。

## 怎麼讀這份紀錄

「一塊」是一個標題（`h1`、`h2`、`h3`、`.card-h`）加上它管的內容，或一張沒有這種標題但有名稱的卡片。

結果只有四種：

- **重建**：改成「一行結論、一個圖或一張 8 列以內的表、其餘摺疊」的區塊。
- **合併**：內容併進另一個區塊，或移到第一屏、組合圖。
- **摺疊**：內容照舊，收在預設關閉的摺疊裡。
- **移除**：不再出現。理由只有三種：**重複**（同樣的內容另有一份留著）、**空殼**（資料來源缺漏時只剩空圖空表）、**沒有用到**（合併成一頁後沒有作用）。

「現在的位置」用頁面上的標記寫，方便用腳本或瀏覽器的檢查工具找到：

| 寫法 | 意思 |
|---|---|
| 第一屏 `data-r2="N"` | 頁首七個讀數的第 N 個，見 [page_markers.md](page_markers.md) |
| 組合圖 | `[data-chart]`，價格、VIX、成交量、崩跌指數同一條日期軸 |
| `plan` | 區塊 `section[data-sec="plan"]` 預設看得到的部分 |
| `plan-1` | 摺疊 `details[data-fold="plan-1"]` |
| 頁尾 | `[data-footer]`，摺疊是 `foot-1`、`foot-2`、`foot-3` |

十個區塊的代號與標題：`plan` 今天怎麼做、`why` 為什麼是這個評級、`paths` 價位與劇本、`crash` 崩跌風險、`mood` 情緒、波動與宏觀、`options` 期權與大戶、`sector` 成分股與費半、`news` 新聞與時事、`proof` 訊號驗證與評級紀錄、`lessons` 崩跌復盤與教訓。

| `options.total_contracts` 是 0，或 `options.focus_strikes` 是空的 | F22、F24、F30、F31、F29 的期權那一列、大戶儀表 | `options` 區塊的一行：`期權資料暫缺：CBOE 選擇權鏈這次沒有回應` |

## 改寫過的讀者文字

資料檔裡存的字串沒有動。頁面在顯示時改寫。

| 原本的文字 | 現在 | 原因 |
|---|---|---|
| 存的字串裡的 `None`、`n/a`、`$None`、`None%` | `暫缺`。同一句裡有兩個以上時，整句換成缺漏說明，句首的標籤（例如 `籌碼：`）留著 | 讀者不該看到程式的佔位符號。規則在 `report_sections.clean()`。 |
| 空括號 `()`、沒有數字的 `$` | 拿掉 | 讀者不該看到程式的佔位符號。 |
| F01 `48 小時內風險：…（排定事件見下方日曆）` | `48 小時內風險（新聞旗標與崩跌指數）：…` | 頁面上沒有日曆。排定事件在簡報 `feed/latest.md`。 |
| S16 第三條 `（上面第一個價位）` | `（見「今天怎麼做」的停損價）` | 那個價位換了位置。 |
| F04、F15 副標裡的 `看完這區就夠做決定`、`請用第 0 區的「名詞小抄」` | 拿掉 | 指向舊版面的位置。 |
| F11 的標題 `交易計畫卡（像 DD 文的 Positions / Plan）` | `以現價計算的簡易計畫`，並註明正式計畫以交易計畫為準 | 兩份計畫的數字不同，要讓讀者分得出來。 |
| F18 讀數是 `None` 卻算成立的項目 | 讀數寫 `資料暫缺`，下面一行 `沒有讀數；模型仍把這一項算作成立` | 項數沒有改，只是不讓讀者誤會。 |
| F42、S18 的免責文字 | 簡報的 `disclaimer` 字串 | 頁面與簡報用同一句，只出現一次。 |
| S14b `偏多評級後 5 日平均 n/a（0 次）` | `偏多評級後還沒有樣本` | 同第一列。 |
| S01a `下次 n/a` | 沒有排程時不寫下次時間 | 同第一列。 |
| F03、F0W 裡的原始錯誤文字 | 只寫來源名稱或失敗的來源數 | 原始錯誤文字不是給讀者看的，而且會帶佔位符號。 |
| 標題裡的表情符號 | 拿掉 | 區塊標題改成固定的短名稱。 |

## 怎麼核對這份紀錄

1. 取出基準頁：`git show baseline:soxl_analysis_report.html`、`git show baseline:soxl_simple.html`。
2. 重畫現在的頁面：`python3 generate_html_report.py --offline`。
3. 對每一列，用「現在的位置」的標記在 `index.html` 裡找到那一塊。摺疊要先打開。
4. 區塊的結論、摺疊、缺漏說明由 `python3 tools/test_report_sections.py` 檢查。
5. 刪除的檔案：`git diff --name-status baseline` 裡狀態是 `D` 的每一列，都要在「刪除的檔案」那張表裡。
